**อะไหล่ที่เปลี่ยน** — เดิมเป็นตารางที่ยืดตามจำนวนจนล้นหน้า ตอนนี้เป็นรายการเรียงเลขไหลเป็น 3 คอลัมน์ (FableB 2 คอลัมน์)
มีบรรทัดสรุปจำนวน + จำนวนที่เคลมประกัน และป้าย "เคลมประกัน" ต่อท้ายชื่อ · ตัวอย่าง Infusion ใส่ไว้ 7 รายการ ใช้ 3 บรรทัด
· หน้าแรกเหลือที่อีกราว 1 บรรทัด = รับได้ถึง ~10–12 รายการ เกินกว่านั้นตัวส่งออกจริงต้องย้ายส่วนที่เหลือไปหน้า 2 (ยังไม่ได้ทำ)

ข้อมูลที่แบบนี้ใช้แต่โปรแกรมยังไม่มี: ผลรายการตรวจ ผ่าน / ไม่ผ่าน / ไม่มี รายข้อ · occlusion 3 ครั้ง (หน่วย kPa, ระดับที่ตั้ง และเกณฑ์

· ผู้ติดต่อ + โทรศัพท์ · ความไม่แน่นอน U · ตำแหน่งผู้ลงนาม (วิศวกรบริการ / หัวหน้าฝ่ายบริการ / ผู้จัดการฝ่ายเทคนิค เป็นค่าสมมติ)
· ชื่อบริษัทและที่อยู่เอามาจากท้ายใบงานเดิม ชื่อภาษาไทยของบริษัทยังไม่ได้ใส่ · ชุด Calibration ทำตัวอย่างเฉพาะ Infusion
(ของ Syringe ใช้หน้ารายการตรวจของ syringe แทนหน้า 1) · ยังไม่ได้ลองพิมพ์บนกระดาษจริง

## ค่าที่บางแบบใช้ แต่โปรแกรม DeltaM ยังไม่มี (ต้องเพิ่มถ้าเลือกแบบนั้น)

- งบความไม่แน่นอน / คอลัมน์ U (k=2) — ทุกแบบ Calibration (ตัวเลขในเอกสารเป็นค่าสมมติ)
- start-up / trumpet curve ตาม IEC 60601-2-24 (รันอย่างน้อย 2 ชม.) — G
- ผล As found / As left ผูกกันในงานเดียว — H
- วันครบกำหนดครั้งถัดไป, รายการตรวจสภาพ/สัญญาณเตือน, Electrical safety IEC 62353 — Inspection หลายแบบ
- QR ตรวจสอบออนไลน์ + ลายเซ็นอิเล็กทรอนิกส์ — B, L
- แบบ Q–Z: กฎ SPC (Q) · กฎตัดสิน guard band + P(ผ่าน) (R) · occlusion/bolus ด้วยตราชั่ง (S, Q-Insp) · ทะเบียนเครื่องมืออ้างอิง
  + log สภาพแวดล้อมเป็นช่วง ๆ (V — ตอนนี้เก็บครั้งเดียวต่องาน) · รวมหลายงานเป็นชุดของโรงพยาบาล (W) · รูปคลื่นอ้างอิงของรุ่นในโปรไฟล์ (X)
  · Allan deviation (Y) · เส้น start-up + ตาราง syringe ต่อรุ่น (Z)
- ข้อมูลที่ **มีแล้ว** ในฐานข้อมูล: ผลย้อนหลังของเครื่อง (I), โปรไฟล์รอบปั๊ม (I, J, M), อะไหล่/ประกัน (I, H), สัญญาณดิบ (M, P), SHA-256 (A, J, L)

## ข้อสังเกตที่รู้แล้ว

- J, O, P, G-Inspection มีพื้นที่ว่างช่วงกลางหน้าค่อนข้างมาก (ลายเซ็นชิดล่างสุด)
- ตัวหนังสือรอบตราประทับของ D ชิดวงนอก · E หน้า Calibration/Inspection มีที่ว่างกลางหน้า
- Q–Z: ค่า Allan (Y), รูปคลื่นรอบปั๊ม (X), เส้น start-up (Z), log สภาพแวดล้อม (V), occlusion/bolus (S) เป็นแบบจำลองสมมติ ไม่ใช่ข้อมูลวัด
- W ใบป้ายสถานะ 90×50 มม. ยังไม่ได้เทียบกับกระดาษสติกเกอร์ยี่ห้อจริง (ระยะขอบ/ช่องไฟต้องปรับตามกระดาษที่ซื้อ)
- ยังไม่ได้ลองพิมพ์บนกระดาษจริง ตรวจจากรูปที่เรนเดอร์ด้วย Edge เท่านั้น
