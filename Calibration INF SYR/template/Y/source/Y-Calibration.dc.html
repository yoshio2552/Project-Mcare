Reading the two charts

The heat map shows every window the result is built from. The pump starts slowly (dashed cells) and DeltaM waits until the flow is steady; the shaded cells after the thick line are the measurement.

The Allan curve shows how the scatter of a single window falls as the window gets longer. At 1 ml/h the balance resolution dominates short windows, so each window must be long (300 s). The dot marks the window used at each rate.

A single window may cross the limit (black cell); the decision uses the mean of all windows, and U already includes this scatter. Windows are chosen per rate and per model + syringe, never one value for all.
